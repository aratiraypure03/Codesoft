Data Science Internship - Projects Overview

1. Titanic Survival Prediction (task1.ipynb)

Objective:
Predict the survival of Titanic passengers based on various features such as age, gender, and class.

Dataset:
Titanic dataset.

Steps:

Data loading and exploration.

Preprocessing: Handling missing values and applying one-hot encoding.

Feature selection.

Hyperparameter tuning using GridSearchCV for models like SVM, Random Forest, Logistic Regression, etc.


Output:
Identification of the best model and its hyperparameters.

2. IMDb Movie Rating Prediction (task2.ipynb)

Objective:
Predict IMDb ratings of Indian movies based on features like genre, duration, director, and actors.

Dataset:
IMDb dataset.

Steps:

Data cleaning and preprocessing: Handling missing values and encoding categorical features.

Splitting data into training and testing sets.

Hyperparameter tuning for regression models such as Random Forest, SVR, Decision Tree, and K-Nearest Neighbors.


Output:
Evaluation of models to determine the best fit.


---

3. Iris Flower Classification (task3.ipynb)

Objective:
Classify Iris flower species based on their sepal and petal dimensions.

Dataset:
Iris dataset.

Steps:

Data loading and exploration.

Splitting data into features and target variables.

Applying models like SVM, Random Forest, Naive Bayes, and K-Nearest Neighbors with hyperparameter tuning using GridSearchCV.


Output:
Identification of the best model and its parameters (SVM and KNN performed best).
